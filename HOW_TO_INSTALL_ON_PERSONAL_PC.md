# 🚀 How to Install and Run OpenShorts on Your Personal PC

Follow these simple steps to run OpenShorts on your personal computer.

---

### Step 1: Prerequisites (Pehle ye 2 cheezein check karein)
Make sure you have these installed on your Windows PC:
1. **Python 3.11 or 3.12:**
   - Download: https://www.python.org/downloads/
   - ⚠️ **VERY IMPORTANT:** During installation, check the box that says **"Add python.exe to PATH"**.
2. **Node.js (LTS version):**
   - Download: https://nodejs.org/ (Download the Recommended LTS version and install it).

---

### Step 2: Download the Project
Aapke GitHub repo se project download karein:
- **Option A (Git):**
  ```bash
  git clone https://github.com/mabsamsungofficial-cyber/OpenShorts.git
  ```
- **Option B (Direct ZIP Download):**
  1. Open: https://github.com/mabsamsungofficial-cyber/OpenShorts
  2. Click **`< > Code`** green button -> **Download ZIP**.
  3. ZIP file ko kisi bhi folder mein extract (unzip) kar lein.

---

### Step 3: 1-Click Launch & Auto-Install
1. Unzip kiye gaye `OpenShorts` folder ko open karein.
2. Wahan ek file hogi: **`Start_OpenShorts.bat`**
3. **Double-click on `Start_OpenShorts.bat`**!

#### 🪄 Ye script kya karega?
* Saari required AI libraries (`faster-whisper`, `ultralytics`, `mediapipe`, etc.) automatically install kar dega.
* Dashboard UI ke dependencies (`npm install`) auto-install kar dega.
* Windows ke sabhi compatibility fixes auto-apply kar dega.
* Aapke **Desktop par ek 'OpenShorts' ka shortcut icon** bana dega.
* **OpenShorts App Window** ko automatically open kar dega (jaise CapCut ya Spotify khulta hai).

---

### Step 4: Daily Use (Roz chalane ke liye)
Agli baar se aapko koi folder bhi open nahi karna padega:
* Bas apne **Desktop par 'OpenShorts' icon par double-click karein** aur software open ho jayega!
* Software band karne ke liye launcher window close kar dein — PC ki RAM turant free ho jayegi.
